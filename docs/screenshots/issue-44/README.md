# Issue #44: 接続要求の履歴

`task gui:demo`（`internal/router/internal/guidemo`）が GUI ルーターを偽の service で起動し、headless Chrome で撮影した（幅 1280）。
デモ用の架空のデータで、未処理 2 件のほかに、許可・拒否・失効が混ざった処理済みの要求 26 件を入れてある（1 ページ 20 件を超えるので、ページ送りが出る）。

| ファイル | 内容 |
|---------|------|
| `requests-pending.png` | 既存の「接続要求」画面（「未処理」タブ）。未処理の要求を許可・拒否する動きは変えていない。見出しの下に「未処理」「履歴」のタブが加わった |
| `requests-history.png` | 「履歴」タブ（`/requests/history`）の 1 ページ目。届いた日時・デバイス名・tailnet IP・ユーザー・結果（許可・拒否・失効・未処理）・処理した日時を、届いた日時の新しい順に 20 件出す。未処理と失効は処理した日時が `-`。右下に「次へ」 |
| `requests-history-page2.png` | 2 ページ目（`?page=2`。「次へ」のクリックで表だけが差し替わり、URL も更新される）。残りの 6 件と「前へ」 |
